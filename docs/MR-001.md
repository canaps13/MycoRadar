## Problèmes rencontrés et corrections vérifiées

- Git/OpenSSL : chaîne de certificats non reconnue. `http.sslBackend=schannel`
  a permis fetch/pull ; réglage limité au clone MycoRadar. TLS reste vérifié.
- Python absent (alias Microsoft Store) : uv et Python ont été téléchargés dans
  `.tools`, environnement virtuel dans `.venv`. Aucun PATH système modifié.
- npm : `UNABLE_TO_VERIFY_LEAF_SIGNATURE`, corrigé par `NODE_USE_SYSTEM_CA=1`.
  L'installation et l'audit ont ensuite réussi sans désactiver TLS.
- Ruff : import initialement mal ordonné, corrigé puis contrôle réussi.
- Starlette : avertissement de dépréciation du client `httpx`, remplacé par
  `httpx2` conformément au client de test installé ; les 3 tests passent sans
  cet avertissement.
- npm émet un avertissement sur `min-release-age`, variable héritée de l'IDE et
  non introduite dans le dépôt. Aucun échec associé lors des validations.
- Après les tests navigateur, Prettier prenait en compte le rapport généré :
  les répertoires de résultats/rapports/couverture sont désormais exclus du
  contrôle de format, comme des fichiers Git suivis.
