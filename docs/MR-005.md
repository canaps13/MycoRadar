- Liens d'entrée dans README et CONTRIBUTING ; aucun adaptateur, service,
  migration, téléchargement massif, compte ou fournisseur activé.

Les sources officielles ont été consultées le 2026-10-29. Le registre relie
les conclusions aux notices et textes ; les droits de cache de fichiers sont
explicitement distingués des conditions de service et signalés comme une
interprétation des droits de reproduction lorsqu'ils sont déduits d'une licence.

## Éléments non établis et accès limités

- BRGM : `license=notspecified` dans la notice du producteur ; une notice tierce
  affiche `lov2`. La page InfoTerre de conditions essayée n'a pas été accessible
  avec l'outil de consultation. Admission bloquée jusqu'aux termes du lot exact.
- OpenObs : page de protection BunkerWeb, pas de texte de licence lu ; aucune
  tentative de contournement. Source bloquée.
- ERA5-Land : fiche lisible, libellé CC-BY, mais texte/version complet non lu.
  Le lien STAC donne une application JavaScript sans métadonnées exploitables
  par l'outil utilisé. Source bloquée ; pas d'acceptation de conditions de compte.
- IGN : anciens liens redirigés vers cartes.gouv.fr ; licences vérifiées dans
  les catalogues publiés par l'IGN, pas déduites des pages produit vides dans
  le lecteur. L'emprise et les caractéristiques du lot RGE ALTI restent à lire.
- SoilGrids : notice annonçant REST suspendu ; les chemins WCS/WebDAV sont des
  alternatives documentées, pas des accès de données testés par cette tâche.
- Deux slugs supposés lors de la recherche catalogue ont répondu 404 ; les
  identifiants corrects ont ensuite été trouvés via l'API catalogue et vérifiés.
- Le lien historique Etalab de licence redirigeait vers data.gouv.fr et le PDF
  n'était pas lisible par l'outil. Le texte LO 2.0 du dépôt officiel Etalab a
  été lu à la place ; aucun échec d'accès n'a été transformé en validation.

Les quotas, la disponibilité des données, les licences des lots et les comptes
non testés sont marqués à vérifier dans les tâches d'adaptateurs. Une notice
accessible ne prouve pas la fraîcheur, la couverture ou la disponibilité d'un lot.

## Risques et retour arrière

Les droits devront être revus à l'intégration puis lors des changements de
version/usage ; le registre ne prétend pas donner une autorisation définitive.
Les sources bloquées peuvent conduire à choisir un autre produit. Les contrats
d'attribution et d'admission décrits sont à implémenter lors des tâches dédiées.
Revert de cette PR pour retirer les documents ; aucune migration ni donnée
applicative affectée. Aucun déploiement, dépense, transmission de données privées
ou modification d'un autre dépôt.
